# Lelelilo 2D

A pillow in a pencil flip book: run, jump, puff, glide, wall jump, dash and flop across a paper pad, the hero in
graphite and the scenery in coloured pencil.

**Play: https://lelelilo-studios.github.io/lelelilo-world-web/**

It needs a browser with WebGPU (Chrome or Edge on a computer, or Safari 26 and later) and a keyboard or a
gamepad: A D or the arrows to move, Space to jump, Shift to dash, S to flop, Esc for every control.

This repository holds only the published build of the game. A game by [lelelilo.com](https://lelelilo.com/?ref=lelelilo-2d).
